06

Motion & Transitions

Animations pensées pour la fluidité : fast pour les micro-interactions, spring pour les entrées d'éléments, smooth pour les transitions de page.

Durées

--duration-fast · 100ms
Hover states, micro-feedbacks
--duration-base · 200ms
Transitions UI standard
--duration-moderate · 300ms
Entrées d'éléments, modaux
--duration-slow · 500ms
Page transitions, reveals
--duration-slower · 700ms
Animations hero, entrées scroll
--duration-sluggish · 1000ms
Effets ambiants, background

Courbes d'accélération

--ease-in-out
cubic-bezier(0.4, 0, 0.2, 1)
Déplacement d'éléments UI
--ease-out
cubic-bezier(0, 0, 0.2, 1)
Entrées d'éléments (décélère en fin)
--ease-spring
cubic-bezier(0.34, 1.56, 0.64, 1)
Boutons, toggles — effet rebond
--ease-smooth
cubic-bezier(0.25, 0.46, 0.45, 0.94)
Transitions de page, hero reveals

Transitions combinées (raccourcis)

--transition-fast
200ms ease-in-out
Colors, opacity, hover states
--transition-base
300ms ease-in-out
Transform, box-shadow
--transition-slow
500ms smooth
Layout shifts, reveals
--transition-spring
400ms spring
Interactions boutons, cartes

Z-Index

Couches d'empilement standardisées pour éviter les conflits et garantir un ordre visuel prévisible.

Token Valeur Usage
--z-below-1Pseudo-éléments de fond, overlays décoratifs
--z-base0Flux normal du document
--z-raised10Cartes hover, éléments légèrement élevés
--z-dropdown100Menus déroulants, popovers
--z-sticky200Header sticky, barre de navigation
--z-overlay300Backdrop des modaux, drawers
--z-modal400Modaux, dialogs, sidebars
--z-toast500Notifications toast, snackbars
--z-tooltip600Tooltips (toujours au-dessus de tout)
